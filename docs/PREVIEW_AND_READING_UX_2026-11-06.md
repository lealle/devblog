# DevBlog 가독성 개선 및 Design Atlas 미리보기 수정 (2026-11-06)

## 진단

- 기존 통합 허브 `public/hub.js`는 디자인 제목·설명·외부 링크만 렌더링했습니다. UI에 실제 시각적 미리보기가 **구현되지 않은 상태**였으므로 사용자는 디자인을 고르기 전에 화면을 볼 수 없었습니다.
- 갤러리 링크는 `target="_blank"`로 열려 인앱 브라우저 팝업 제약이 있는 환경에서 사용하기 불편할 수 있었습니다. 이 부분은 잠재적 호환성 위험이며 실제 재현 여부는 별도 브라우저 검증이 필요합니다.
- DevBlog 기본 화면은 글 목록의 날짜·출처·요약이 비교적 평면적으로 제시되었고, 전체 검색에는 추천 검색어·비어 있는 결과 안내가 없었습니다.

## 변경 내용

### 통합 허브 디자인 미리보기

- Design Atlas가 자체적으로 제공하는 공개 정적 HTML을 사용해 각 카드의 **실제 시안 축소 미리보기 iframe**을 표시합니다.
- IntersectionObserver + lazy loading으로 보이는 카드 중심으로 프레임을 불러오며, 초기 페이지는 12개 카드로 제한합니다.
- 미리보기 버튼을 누르면 `dialog.showModal()`로 큰 화면에서 실제 디자인을 렌더링합니다.
- 디자인 100개 시안에서는 **개발 블로그·메인·프롬프트 예시** 화면 모드를 바꿀 수 있고, 42개 체험형 디자인은 인터랙티브 원본을 표시합니다.
- 인앱 브라우저에서 팝업이 차단되어도 쓸 수 있게 `원본 열기`는 현재 탭으로 이동하도록 했습니다.
- 미리보기를 못 불러오는 환경에는 원본 링크가 남아 있습니다.
- URL은 공개 `https://lealle.github.io/design-atlas/` 경로만 허용하며 사적인 `prompt-library`·`dev-kit`의 데이터는 가져오지 않습니다.
- 새로운 JavaScript와 CSS는 캐시 버전을 변경해 오래된 브라우저 캐시로 화면 코드가 어긋나는 문제를 줄였습니다.

### DevBlog

- **최신 글**: 상단 내비게이션, 큰 소개 제목, 최근 기사 및 누적 수집 건수, 국내/해외 필터, 결과 개수, 카드별 제목/출처/요약 계층화, 검색 결과 0건 메시지
- **전체 검색**: 같은 내비게이션, 추천 검색어, 지역·기술·정렬 필터의 3열 배치, 문제 해결 검색 모드, 결과 카드 2열 및 모바일 1열, 검색 결과 0건 메시지
- CSS를 `public/blog-ui.css`로 공통 관리하고 기존 RSS 수집·중복 제거·분류·검색 색인 빌드 함수는 보존했습니다.
- `prefers-color-scheme`과 `prefers-reduced-motion`, 포커스 표시, `aria-pressed`, `aria-live`, 건너뛰기 링크를 유지하거나 강화했습니다.

## 테스트 및 확인

- Python 단위 테스트: 새 렌더러의 시맨틱 마크업/기사 HTML 이스케이프, 검색 필터 DOM 계약, 미리보기 DOM 및 공개 데이터 전용 색인 검증
- JavaScript 구문: `hub.js`, `search.html` 스크립트, `render.py`에서 생성하는 스크립트
- 정적 빌드: `render.py`, `build_search_index.py`, `build_resource_hub.py` (공개 디자인 142개)
- Pages 배포 파일과 참조 링크 존재 여부를 GitHub Actions에서 확인
- GitHub Actions 성공과 실제 인앱 브라우저·프레임 로딩 경험은 **서로 다른 검증**입니다. 실제 브라우저 접속 시험을 하지 않았다면 미검증이라고 명시합니다.

## 남은 개선

- 브라우저/플랫폼마다 iframe 정책이 다를 수 있으므로 실제 모바일 및 인앱 브라우저의 iframe 로딩 결과 확인
- 자주 쓰는 디자인 시안 썸네일을 정적 이미지로 사전 생성하면 초기 CPU/네트워크 비용을 더 줄일 수 있음
- 전체 기술 문서 색인 용량이 증가하면 색인 분할 또는 검색 엔진 교체 전 성능을 측정할 것
- 비공개 Prompt Library는 공개 사이트에 프롬프트 내용을 가져오는 방식으로 통합하지 않음
